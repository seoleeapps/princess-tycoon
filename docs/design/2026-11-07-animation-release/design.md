# 활동 애니메이션 Google Play 업데이트

2026-11-07 사용자 지시 「빌드 배포해」를 근거로, main `7307bba`에 병합된 PixelLab 활동·환경 애니메이션 8종을 Google Play에 배포한다. 기존 한국 무료 배포, Seolee Apps 개인 계정 `5547060480954653351`, 패키지 `com.seoleeapps.princesstycoon`, 광고·인앱 결제 없음, 전체 배포(100%)를 유지한다. 이번 지시는 완료된 애니메이션 구현 계획의 `release: null` 이후 받은 새 출시 승인이다. 이전 구현과 최초 출시 기록은 보존한다.

새 버전은 `1.0.1`, versionCode `3`이다. 2026-11-07 API 조회에서 사용된 코드는 1·2이며 production과 internal은 `1.0.0 (2)`로 읽혔다. 이 트랙 상태만으로 공개를 판정하지 않고 Console 심사·게시·공개 스토어 상태를 별도로 확인한다.

실행은 저장소의 기존 `docs/google-play-release.md` 수동 절차를 따른다. 이 seoleeapps 저장소에는 중앙 release-tag/deploy caller나 버전 원장 브랜치가 없으므로 Seorilabs 조직 파이프라인을 새로 만들지 않는다. 앱 버전은 Android export와 Play config에 함께 반영하고, 검증된 후보를 `v1.0.1` 태그로 고정한다. 태그를 실제 생성하기 전에는 생성 완료로 기록하지 않는다.

테스트는 L1/dev이며 기존 게임 실행 코드와 8종 이미지에 새 변경을 하지 않는다. `npm test`, headless E2E, 렌더링 E2E, 3개 viewport 전체 루프, Web export, Play config 검사와 Android AAB 빌드를 실행한다. 버전 메타데이터는 TDD 대상 동작이 없으므로 실제 AAB의 패키지·버전·SDK·권한·업로드 서명과 API 수신 해시를 대조한다. 재생 상태·저장·장비·활동 선택은 기존 실제 main 여정과 68개 애니메이션 검사로 확인한다.

네이티브 플러그인, SDK, 권한, 입력·저장 어댑터와 엔진을 바꾸지 않는다. 이번 변경에 개발 환경으로 확인할 수 없는 필수 항목은 없으므로 기기를 사용하지 않는다. 이전 AND-01~07 기록을 이 후보의 새 기기 실행으로 표시하지 않는다. 기존 custom Theme 때문에 별도 UI 정적 스캐너가 7 FAIL이었던 사실도 보존하며 통과로 바꾸지 않는다.

같은 AAB를 내부 테스트에 올려 정확한 코드·상태·처리 결과를 읽고 프로덕션으로 승격한다. 국가, 출시 노트, 정책·등록정보, 관리형 게시 설정과 실제 제출 상태를 다시 읽는다. 기존 심사 철회나 지원팀 연락, 계정·권한·서명 변경이 필요해지면 별도 권한을 확인한다. 승인 대기를 공개 완료로 표시하지 않으며, 승인 후 설정된 게시 방식과 공개 스토어 readback까지 진행한다.

최초 출시 원장은 `release/history/1.0.0.json`에 그대로 보존하고 현재 실행은 새 `release/market-launch-state.json`에 기록한다. 생성물과 전체 로그는 NAS1dual/Data에 ZIP으로 이관해 ZIP 전체와 내부 크기·SHA-256을 검증한 뒤 로컬에서 정리한다. 빌드, 내부 테스트, 프로덕션 제출, 승인과 공개는 각각 별도 관문이다.
