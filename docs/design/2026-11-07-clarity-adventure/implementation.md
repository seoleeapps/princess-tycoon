# 목표 안내와 모험 장면 구현

홈은 자동 활동, 성장 방향, 진로 칭호 수집을 설명하고 현재 상태로 첫 심사와 다음 해금·진로 조건을 보여 준다. 메뉴의 육성 안내에서 흐름을 다시 볼 수 있다. 심사 일수는 게임 속 시간임을 표시한다.

수동 원정은 A 장면으로 열리고 자동 원정은 홈 안에서 재생한다. 탐색 사건, 조우와 보스, 실제 공격 피해·HP, 후퇴와 보상을 보여 준다. 전리품은 이름별 수량으로 합친다. `결과 보기`, `일시정지`, `닫기`와 홈의 `크게 보기`를 좌표 입력으로 검증한다. 재생 시간은 main의 UI 상태에만 있으며 장면을 보거나 건너뛰거나 다시 열어도 판정·보상을 다시 실행하지 않는다. 수동 장면 도중의 자동 결과는 별도 시계에 보관한다.

오프라인은 기존 정산 요약을 먼저 보여 준다. 현재 세션의 최근 원정 하나만 선택해서 다시 볼 수 있다. 이전 결과에 세부 전투 기록이 없으면 알려진 노드·남은 HP와 참조 자세만 표시한다. 새 수련생을 만들면 이전 세션의 장면을 비운다. 저장 실패 때는 성공 연출 대신 저장 실패와 재시도 방법을 알린다.

선택한 모션은 60개다. 생성 응답의 실제 청구량은 **508 generations / 작업 상한 576**이며 `assets/pixellab_v2/provenance.json`에 각 job ID와 차감량을 남긴다. 정적 생성 38회, 모션 생성 64회다. 파일럿 피격 모션 1개와 재생성으로 대체한 모션 3개도 실제 차감량에 포함한다. 박쥐 무리의 패배, 균열 짐승의 공격, 기계형 보스의 패배를 각각 한 번 재생성했다. 공유 계정 잔액 차이를 비용으로 쓰지 않는다.

도트 1픽셀은 논리 2픽셀로 nearest 렌더링한다. 몸과 소품은 프레임별 부착점으로 합성하며 캐시는 상한을 둔다. 모션 줄이기는 참조 자세와 확정 결과를 제공하고, 일시정지·비활성·홈 이탈 때 재생 시계를 멈춘다. 일시정지 시 진행 중인 장식 효과를 정리한다. 기존 64×64 활동·환경 모션 8종은 계속 사용한다.

공통 UI는 game-foundation `ca2ff1f22b3b3aa0ffb718639a980d4d4bb5b6b8`의 ui_kit 구성요소 16파일을 그대로 가져왔다. 원본 해시와 MIT 라이선스를 보존한다. 전체 outgame 번들을 설치한 것으로 표시하지 않는다. 제품용 픽셀 스킨, Neo둥근모·Galmuri 역할 서체, 버튼 효과음, 팝업 페이드, 보상·파티클, HUD 레이어와 재화 칩을 실제 화면에서 사용한다.

## 검증 기록

표시 필드를 제외한 기존 게임 상태는 main 기준의 18개 고정 사례와 1,000슬롯 비교로 검증한다. 테스트는 활동·성장·장비·해금·보상·저장·오프라인·재시작을 포함하며, 새 목표·장면·파손 기록·저장 실패·재생 수명과 에셋을 별도로 검사한다. 저자 개발 중 실패 로그는 최종 검수와 구분해 보존한다.

L3/dev 독립 검수 3회는 회차별 사전 계획, 같은 후보 SHA, 실제 명령·로그·화면과 기능·UX 판정을 남긴다. 최종 실행 판정과 검증된 NAS 원본 위치는 병합 PR의 검증 목록에 연결한다. 이 문서는 구현 계약이며 사전 실행을 최종 검수로 승격하지 않는다.
