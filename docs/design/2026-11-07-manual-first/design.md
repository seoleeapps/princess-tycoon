사용자 2026-11-07의 세 가지 수정 지시를 구현한다. 첫 자동 진행은 꺼 두고 충분히 익힌 뒤 켜도록 안내하며, 홈의 방치 8시간 버튼은 실제 미정산 결과가 있을 때 정산하기로 표시하고, 성장 방향 선택은 계획 탭으로 모은다. 기존 A 화면·아트·스킨을 재사용하는 좁은 상태/문구/중복 컨트롤 수정이며 새 화면이나 시각 방향 개편은 아니다.

기준 main b7370422b451fd3e81a1a7fbee96d27d40c475f3. 사용자 직접 지시가 변경 범위의 승인 근거다. L1/dev, redesign:false, release:null. main PR 병합까지 진행하며 기기·마켓·추가 생성은 포함하지 않는다.
