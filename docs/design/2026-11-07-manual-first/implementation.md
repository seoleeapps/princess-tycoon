# 직접 체험 후 자동 진행 구현

신규·새 수련생·초기화는 자동 OFF다. 수업/휴식을 직접 익히고 활동8회 뒤 계획에서 방향을 고르면 기존 홈 다음 행동 카드에서 자동 진행 켜기를 안내한다. 클릭하지 않으면 켜지지 않으며 설정에서의 명시적 선행 선택도 허용한다. 한 번 켠 뒤의 일시정지에는 첫 안내를 반복하지 않는다.

홈의 성장 방향 선택 CTA와 성장 방향 바로가기를 제거했다. 계획 탭의 선택은 유지한다. 미정산이 없으면 정산 버튼을 숨기고 실제 pending>0이면 정산하기를 보여 준다. 과거 정산보다 현재 대상을 우선 표시하며 정산 대기 중 자동 변경과 중복 정산으로 결과가 소실되거나 덮이지 않게 한다.

새 저장의 autoRun 기본값만 false이며 기존 true/false와 키가 없던 구형 저장의 종전 기본 true는 유지한다. 첫 자동 시작 시 학습 중 대기 시간을 제외한다. 새 수련생/초기화는 진행 게이지도 비운다. 경제·판정·난수·해금 수치·아트·마켓 설정은 바꾸지 않았다.

MF-01~05 단위/런타임 요구사항 RED를 먼저 기록했고, 기존 자동 ON 검사의 fixture를 명시적으로 ON으로 바꿔 종전 모션·오프라인·1,000슬롯 baseline 비교를 유지했다. 변경된 초기 상태의 실제 입력은 기존 E2E에 추가했다. 실행 결과·실패 원본·실제 렌더·NAS 경로는 최종 후보 PR에 연결하며 이 문서를 실행 통과 근거로 대체하지 않는다.
