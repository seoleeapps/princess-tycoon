# 안전 영역 알림 수명 수정

초기화 전 또는 트리에서 분리된 MainScreen에 포커스·복귀 알림이 들어오면 get_viewport()가 null인 상태에서 get_visible_rect()를 호출했다. 삭제 대기 중에는 늦은 알림이 저장 기준시각과 여백을 바꾸기도 했다.

포커스·정지 플래그는 즉시 보존하되 트리 안에서 ready가 끝났고 삭제 대기 중이 아닐 때만 후속 UI·엔진·저장을 처리한다. 안전 영역 콜백은 Viewport를 한 번 받아 null과 삭제 대기를 확인한다. ready 내부의 최초 여백 적용은 유지한다.

사용자와 같은 스택 오류를 RED로 재현했고 초기화 전, 트리 진입 중, 정상 포커스 복귀, 분리된 노드에 연결된 size_changed, 재진입, queue_free 대기를 포함한15개 검사가 GREEN으로 바뀌었다. 정상 수동 모드 복귀의0slot 정산도 유지한다. 전체 실행·로그·실제 화면과 NAS 무결성 결과는 최종 후보 PR에 연결하며 새 마켓 배포나 기기 실행을 통과했다고 표시하지 않는다.
