## 데이터와 정책

게임은 네트워크를 쓰지 않는다. 분석 포트는 기기 안 메모리에만 기록하고 광고·결제 포트는 no-op이다. 그래서 데이터 보안은 "수집·공유 없음"으로 신고한다. 개인정보처리방침은 서리랩스 공용 페이지 `https://www.seorilabs.com/privacy/`를 쓰고, 출시 전 응답(200)과 내용을 확인한다. 고객 지원 연락처는 `cs@seorilabs.com`이다. 원작 분석 자료(`extract/`, `docs/00~09`)는 `godot/` 밖이라 빌드에 들어가지 않고, 등록정보에서 원작을 언급하지 않는다.

## 실기기 확인(승인 범위)

개발 환경은 Godot headless·렌더링 E2E로 전체 흐름을 확인한다. 아래는 실제 Android 런타임과 기기에서만 드러나는 항목이라 승인받은 기기 1대에서 다른 에이전트가 Play 내부 테스트 설치본으로 확인한다.

| ID | 항목 | 개발 환경으로 확인할 수 없는 이유 |

| AND-02 | 실제 터치 탭·끌기·관성 | 실제 터치 이벤트와 기기 입력 지연 |
| AND-03 | 강제 종료 뒤 저장 유지 | Android 앱 저장소 경로와 프로세스 종료 |
| AND-04 | 백그라운드 복귀 오프라인 정산 | Android 수명 주기(일시정지·재개) |

### 1차 결과(versionCode 1, 2026-11-06)

Solana Mobile Seeker(Android 16, 1200×2670)에 Play 내부 테스트로 설치해 다른 에이전트가 확인했다. 기기 사용은 약 18분이다.

| ID | 결과 | 관찰 |
|---|---|---|
| AND-01 | 통과 | cold start 257ms, 홈 화면과 픽셀 폰트 정상, 앱 오류 로그 없음 |
| AND-02 | 통과 | 카드 위 끌기 스크롤, 빠른 밀기 관성 |
| AND-03 | 통과 | 강제 종료 뒤 연차·시즌·골드·최근 활동 유지 |
| AND-04 | 통과 | 153초 백그라운드 뒤 같은 프로세스로 복귀, 오프라인 정산 2회 |
| AND-05 | 실패 → 수정 | 뒤로 가기 한 번이 두 단계로 처리됨(6회 중 4회). Godot Android가 같은 누르기를 키 입력과 시스템 뒤로 가기 콜백 두 경로로 엔진에 보낸다. 300ms 안에 겹쳐 온 요청은 한 번만 처리한다 |
| AND-06 | 실패 → 수정 | Android 16은 edge-to-edge를 강제해 상단 바가 카메라 컷아웃 띠(위 78px)까지 올라옴. 화면 전체를 컷아웃 안전 영역 안으로 줄이고 여백은 화면비 여백과 같은 검정으로 칠한다 |
| AND-07 | 미완료 | 기기 미디어 볼륨이 음소거라 소리를 듣지 못함. 앱 오디오 트랙은 활성 |
