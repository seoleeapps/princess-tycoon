## 의도한 차이

| 항목 | 시안 | 실행 화면 | 이유 |
|---|---|---|---|
| 현재 활동 창 | 이름, 게이지, 60%, 일시정지 | 진행 고리, 이름, 다음 선택 이유, 방치 8시간, 일시정지 | GDD 10.2는 현재 활동, 다음 선택 이유, 오프라인 상한, 일시정지를 모든 탭에서 보여야 한다. 창 하나를 홈에서는 장면 위, 다른 탭에서는 셸에 둔다 |
| 최근 결과 위치 | 행동 버튼 위 | 행동 버튼 아래 | 결과 줄 수가 늘어도 주요 행동 버튼 위치가 바뀌지 않게 한다 |
| 골드 표기 | 2,840 G | 2.8천 G | 게임의 큰 수 표기 규칙(`_format_big`)을 따른다 |
| 720×1280 E2E | 없음 | 390폭 장면 좌우에 어두운 여백 | E2E는 viewport 크기를 논리 크기로 쓴다. 실제 기기는 `canvas_items + keep`으로 논리 390×844를 유지한다(1170×2532 기기 배율 렌더로 확인) |
