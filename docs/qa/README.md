# 모바일 렌더 QA

Godot GL Compatibility 실렌더 결과다(2026-11-04 픽셀 UI, 2026-11-05 단계적 해금 뒤 갱신, Godot 4.7.2 macOS). 홈 렌더는 새 게임 첫 화면이라 해금 1단계(홈·활동 탭, 행동 1개)다. `godot/tests/render_capture.gd`가 격리된 테스트 세이브로 메인 씬을 띄우고, 390×844 좌표계를 기기 해상도에서 직접 그린다. 글자와 도트를 확대하지 않고 기기 배율로 래스터하므로 실제 기기와 같은 굵기로 보인다.

- `mobile-390x844.png`: 논리 기준 화면(1배)
- `device-1170x2532.png`: 390pt 폭 휴대폰(3배)
- `device-1290x2796.png`: 430pt 폭 대형 휴대폰(3배)
- `device-720x1280.png`: 720px 폭 안드로이드(1.52배, 좌우 pillarbox는 `keep` 정책)
- `result-feedback-390x844.png`: 수동 활동 완료 결과 창(능력치 칩이 모두 나타난 뒤)

레이아웃 자동 검증(`layout_probe.gd`)은 390×844, 430×932, 720×1280 논리 크기에서 12개 기능 경로의 필수 CTA를, 390×844에서 도트 격자와 실제 바탕 대비를 확인한다. 상세 명령과 결과는 `../12_구현_QA_증거.md`를 따른다.
