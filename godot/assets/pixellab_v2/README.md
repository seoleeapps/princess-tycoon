# 아카데미 캐릭터와 탐험 아트

PixelLab의 `generate-image-v2`로 주인공 의상 5종, 지역·생활 배경 9종, 적 15종, 장비 소품 9종을 제작한다. 선택한 주인공을 스타일 기준으로 사용하며 원작 추출물은 사용하지 않는다. 제작 때만 API를 호출하고 런타임은 PNG 아틀라스와 JSON을 읽는다.

- 주인공: 따뜻한 갈색 반묶음 머리, 아이보리 셔츠와 청록 망토를 입은 성인 수련생. 5개 의상에서도 얼굴·체형·머리를 유지한다.
- 배경: 아카데미, 도서관, 왕도, 경기장, 숲, 동굴, 유적, 화산, 균열. 192×176 PNG를 nearest로 2배 그린다.
- 모션: `animate-with-text-v3`, 128×128, 투명 배경, 클립당 8프레임. 주인공은 대기·걷기·공격, 적은 대기·공격·패배다. 반복 또는 시작 자세로 돌아오는 모션은 같은 first/last frame을 보낸다. 패배는 마지막 자세를 유지한다.
- 아틀라스: 8프레임 뒤의 9번째 칸은 정지 참조다. 주인공은 성장 방향 8개의 색을 행으로 구워 1152×1024, 적은 1152×128이다. 원본 redraw는 재생 프레임에서 제외한다.
- 합성: 208×160 캔버스, 몸 위치 (24,16), 발 기준 (88,137). 접지하는 몸은 원본 발 높이 121에 맞춘다. 떠 있는 생물의 상하 움직임은 유지한다. 장비는 프레임별 손·가슴·머리 기준점에 붙이고 무기는 공격 방향으로 회전한다.
- 속도: 대기·걷기 6fps. 공격·패배는 실제 결과 단계의 진행률에 맞춰 한 번 재생한다. 모션 줄이기에서는 참조 자세와 확정 결과를 표시한다.
- 저장·난수: 재생 시계·텍스처 캐시는 UI에만 있다. 장면을 보거나 건너뛰어도 판정이나 보상을 다시 실행하지 않는다.

제작 명세·선택·변환기는 `scripts/pixellab_redesign/`에 있다. `provenance.json`은 각 작업의 응답에 있는 실제 generations 차감량을 합산하며 공유 계정 잔액 차이를 비용으로 추정하지 않는다. 작업 상한은 576 generations다. 접수 결과가 불명확한 POST는 재시도하지 않고 알려진 job ID만 재개한다. 품질 재생성은 에셋당 1회까지다.

원본 응답과 개별 프레임·검수 자료의 검증된 NAS 경로는 설계 폴더의 실행 보고서에 기록한다. 이 폴더는 기존 `assets/pixel/` 생성기와 별도로 관리한다.

공식 명세: [정적 이미지](https://www.pixellab.ai/docs/tools/create-sl-image-pro), [텍스트 애니메이션](https://www.pixellab.ai/docs/tools/animate-with-text-new).

현재 생성 완료 기록은 정적 38회와 모션 64회, 총 508 generations다. 선택한 모션은 60개이며 파일럿 1개와 재생성으로 대체한 3개도 청구 기록에 포함한다. 재생성한 대상과 이유는 `quality-retries.json`에 보존한다.
